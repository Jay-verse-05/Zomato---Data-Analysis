
# 🍽️ Zomato Data Analysis

## 📌 Project Overview
This project focuses on analyzing Zomato restaurant data to uncover insights into restaurant ratings, customer preferences, pricing trends, popular cuisines, and online ordering patterns.

The objective is to explore the dataset, identify trends, and generate actionable insights that support data-driven decision-making in the food and restaurant industry.

## 🎯 Objectives
- Analyze restaurant distribution across different locations.
- Understand restaurant ratings and customer preferences.
- Explore the relationship between restaurant ratings and cost.
- Identify popular cuisines and restaurant categories.
- Analyze online ordering and table booking trends.
- Visualize key performance indicators and business insights.

## 📂 Dataset
The dataset may contain the following information:
- Restaurant Name
- Location and City
- Cuisines
- Aggregate Rating
- Approximate Cost for Two
- Online Order Availability
- Table Booking Availability
